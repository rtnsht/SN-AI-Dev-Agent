Authentication Flows

Request Access
POST /api/auth/request-access
users→ access_requests→ auth_tokens
Verify OTP
POST /api/auth/verify-otp
auth_tokens→ access_requests→ users→ sessions
Login (password)
POST /api/auth/login
users→ users→ sessions
Magic Link Login
POST /api/auth/verify-magic-link
auth_tokens→ auth_tokens→ users→ sessions
Register via Invite
POST /api/auth/register-invite
invite_codes→ users→ invite_codes→ sessions
Forgot Password
POST /api/auth/forgot-password
users→ auth_tokens

App Usage Flows

Connect to ServiceNow
POST /api/session-start
sessions→ user_instances→ session_logs
Send Chat Message (authenticated)
POST /api/chat or /api/chat-stream
access_tier_config→ request_log→ request_log
Send Chat Message (anonymous)
POST /api/chat or /api/chat-stream
access_tier_config→ anon_request_log→ anon_request_log
Submit Feedback
POST /api/feedback
users→ feedback_reports
Logout
POST /api/auth/logout
sessions

Admin Flows

Approve Access Request
PATCH /api/admin/requests/[id]
access_requests→ access_requests→ users→ auth_tokens
Suspend User
PATCH /api/admin/users/[id]
users→ sessions
Manage Banners
/api/admin/banners
banners→ banners
Configure Trials / Tiers
/api/admin/trials & /api/admin/access-tiers
trial_config access_tier_config→ trial_config access_tier_config
