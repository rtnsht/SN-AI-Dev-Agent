Authentication Flow (Email-First)

ConnectModal state machine → session creation
sequenceDiagram autonumber participant U as Browser
(ConnectModal) participant API as Auth API Routes participant DB as Supabase participant EM as ZeptoMail Note over U: Step 1: Email Entry U->>API: POST /api/auth/check-email
{email} API->>DB: SELECT from users WHERE email API->>DB: SELECT from access_requests WHERE email alt User exists with password API-->>U: {step: "password"} U->>API: POST /api/auth/login
{email, password} API->>DB: Verify bcrypt hash API->>DB: INSERT sessions {token, user_id} API-->>U: Set-Cookie: sn-ai-session U->>U: Redirect to /app else User exists, approved, no password API-->>U: {step: "otp_verify"} API->>DB: Create OTP token (6-digit, 10min expiry) API->>EM: Send OTP email U->>API: POST /api/auth/verify-otp
{email, otp} API->>DB: Validate OTP token API->>DB: INSERT sessions (temporary) API-->>U: Set-Cookie + redirect /auth/set-password U->>API: POST /api/auth/set-password
{password} API->>DB: UPDATE users SET password_hash API->>DB: Upgrade session (temporary → permanent) API-->>U: Redirect to /app else New user (not found) API-->>U: {step: "request_access"} U->>API: POST /api/auth/request-access
{name, email, company, use_case} API->>DB: INSERT access_requests (pending_verification) API->>DB: Create OTP token API->>EM: Send verification OTP API-->>U: {requiresOTP: true} U->>API: POST /api/auth/verify-otp
{email, otp} API->>DB: UPDATE access_requests SET email_verified Note over API: If auto-approve enabled: API->>DB: INSERT users + INSERT sessions API-->>U: Set-Cookie + redirect end

3-Tier Access Control

checkAccess() gate on every /api/chat* request
sequenceDiagram autonumber participant REQ as Incoming Request participant GATE as access-tier.ts
checkAccess() participant DB as Supabase REQ->>GATE: checkAccess(ip, userId, isByok, instanceUrl) alt Tier 3: BYOK (user API key) GATE-->>REQ: ALLOW (unlimited) else Tier 2: Authenticated User GATE->>DB: SELECT request_log WHERE user_id, today DB-->>GATE: authUsed count GATE->>DB: SELECT anon_request_log WHERE ip, today DB-->>GATE: anonUsed count GATE->>GATE: combinedUsed = authUsed + anonUsed alt combinedUsed < authDailyLimit GATE->>DB: UPSERT request_log (increment) GATE-->>REQ: ALLOW {tier: "authenticated", used, limit} else GATE-->>REQ: DENY {gate: "apikey"}
Show APIKeyGateModal end else Tier 1: Anonymous GATE->>DB: SELECT anon_request_log WHERE ip, today DB-->>GATE: ipTotal GATE->>DB: SELECT anon_request_log WHERE instance_url, today DB-->>GATE: instanceTotal GATE->>GATE: usage = max(ipTotal, instanceTotal) alt usage < anonDailyLimit GATE->>DB: UPSERT anon_request_log (increment) GATE-->>REQ: ALLOW {tier: "anonymous", used, limit} else GATE-->>REQ: DENY {gate: "signup"}
Show SignupGateModal end end
