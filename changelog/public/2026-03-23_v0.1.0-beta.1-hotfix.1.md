# v0.1.0-beta.1-hotfix.1 — CDN Cache Fix

**Release Date:** 2026-03-23

---

## Fixed

- **Page Loading Issue** — Fixed an intermittent issue where the app page would display garbled text instead of the normal UI. This was caused by Cloudflare CDN caching an internal Next.js data format and serving it to visitors expecting a normal page load. The fix adds explicit cache-control headers that prevent CDN caching of dynamic pages while preserving fast caching for static assets (JavaScript, CSS, fonts).

## What You Might Have Seen

If you hit this bug, you would have seen raw text starting with `:HL["/_next/static/...` instead of the app interface. A hard refresh (Ctrl+Shift+R / Cmd+Shift+R) or clearing your browser cache would temporarily fix it, but the issue could return.

After this fix, the issue will not recur.
