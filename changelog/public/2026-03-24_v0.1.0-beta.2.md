# v0.1.0-beta.2

**Release Date:** 2026-03-24

---

A quality, security, and feature update with 29 commits since beta.1. Adds voice input, BYOK transparency, ATF testing tools, social sharing, admin engine controls, and a sweep of bug fixes from multi-agent code review.

## Added

- **Voice Input** — Speak your requirements instead of typing. A 3-tier fallback ensures it works across all browsers:
  - Chrome/Edge/Safari: native Web Speech API (zero cost)
  - Brave/Firefox: on-device Whisper via transformers.js in a Web Worker (~41 MB model, cached in IndexedDB, no data leaves the browser)
  - Last resort: server-side OpenAI Whisper API proxy (~$0.006/min, requires OPENAI_API_KEY)

- **ATF Testing Tools** — The agent can now create ATF test suites, run them, and poll results directly from the chat. Quality scan tools are also available during the deployment phase.

- **Social Share Prompt** — After a productive session (5+ minutes, 2+ phases completed), the app offers to help you share your experience. Includes AI-generated hashtags, OG share card preview, and LinkedIn/X share links with download option. All tracked via Supabase with HMAC fingerprinting.

- **Admin Engine Configuration** — New "Engine" tab in the admin dashboard. Configure per-phase round limits, planner budget factor, and default round limits — all hot-reloadable with a 5-minute cache per serverless worker.

- **API Key Pool Rotation** — Set multiple API keys via `CLAUDE_API_KEYS` / `OPENROUTER_API_KEYS` (comma-separated). Sessions are sticky-assigned to a random key from the pool, distributing load across keys.

- **AI Disclaimer** — A brief AI disclaimer is now displayed below the chat input.

- **BYOK Security Transparency** — A new collapsible "Key Security" disclosure in both the Settings panel and the API Key Gate modal explains exactly how your API key is handled: browser-memory-only storage, HTTPS transport, transient per-request usage, log redaction, and the server-proxy architecture. Includes a recommendation to use dedicated keys with spend limits.

- **BYOK Enabled by Default** — The BYOK (Bring Your Own Key) toggle is now active. Users can switch between Server Keys and BYOK to use their own Anthropic or OpenRouter API key for unlimited usage.

## Improved

- **Mermaid Diagrams** — Pre-validation with `mermaid.parse()` before rendering prevents DOM error banners. Added a DiagramErrorBoundary wrapper and an ASCII diagram tab (triggered by `%% @ascii` comments in mermaid blocks) as a fallback viewer.

- **Message Queue Panel** — Queued follow-up messages moved from inline chat bubbles to a collapsible panel above the input bar for a cleaner conversation flow.

- **SDLC Phase Rounds** — Design phase increased from 20 to 25 rounds, implementation from 30 to 40, and testing from 20 to 40. System prompt rewritten for testing, deployment, and rollback sections.

- **Error Handling** — Unified provider error taxonomy (`provider_rate_limit`, `provider_auth`, `provider_billing`) with a `usedServerKey` flag that triggers the BYOK gate only when the server key is at fault. Streaming SSE errors now detect provider issues inline.

- **BYOK Branding** — All references to "Your API Key" replaced with "BYOK" throughout the UI — settings panel, error messages, gate modal, and server responses.

- **API Key Gate Modal** — Now shows context-specific copy for auth errors vs billing limits vs rate limits. Includes `role="dialog"` and `aria-modal` for accessibility.

## Fixed

- **Cloudflare RSC Cache Poisoning** — Fixed an intermittent issue where Cloudflare cached React Server Components flight data and served raw `:HL[...]` text instead of the rendered page. Added CDN-specific cache-control headers for all dynamic routes.

- **Voice Mode Instant-Stop** — The `Permissions-Policy` header was set to `microphone=()`, blocking all mic access. Changed to `microphone=(self)` and added proper error differentiation for fatal vs non-fatal speech recognition errors.

- **Anthropic 400 Dedup Warning** — Resolved `dedup_warning` errors by sanitizing API error responses before returning them to the client.

- **Assistant Prefill Error** — Fixed Claude 4.5+ "assistant message prefill" 400 error by splicing planner data before the last user message instead of after.

- **Share Tag Key Resolver** — `generate-share-tag` was reading `process.env.CLAUDE_API_KEY` directly instead of using the pool resolver. Now uses `resolveLlmApiKey()`.

- **Non-Streaming Provider Auth** — The `provider_auth` condition was missing from the non-streaming error handler, preventing the BYOK gate from triggering on auth errors.

- **Session Binding Memory Leak** — Added FIFO eviction cap (10K entries, evict oldest 2K batch) to the key-resolver session binding map.

- **Config Pool Size Exposure** — Removed `keyPoolSize` from the public `/api/config` response to avoid leaking infrastructure details.

- **Log Storage Sync Init** — `LogStorageSync` was never initialized because `getLogStorageSync()` was only called from a rarely-hit admin endpoint. Now initializes from `logger.ts` on first log event.

- **S3 ForcePathStyle** — Made `forcePathStyle` configurable per storage provider. DigitalOcean Spaces requires `false` (virtual hosted-style) while Supabase Storage S3 requires `true` (path-style).

- **Changelog Auth** — Added `/api/changelog` to public paths so the "What's New" dropdown works for unauthenticated users.

- **Docker Build Vars** — Added missing `NEXT_PUBLIC_*` variables to Dockerfile and render.yaml for proper build-time inlining.

- **Mermaid Init Race Condition** — Serialized mermaid initialization with a module-level Promise. Reset on rejection so future diagrams can retry instead of permanently blocking rendering.

- **OpenRouter Context Trimming** — Added `trimConversationHistory` to the OpenRouter streaming path (was missing, only Anthropic had it).

## Security

- **Multi-Agent Code Review** — All changes reviewed by 7 independent AI agents in a second-pass audit. All HIGH, MEDIUM, and LOW findings addressed.

- **Request Validation Hardened** — Reject NaN and non-integer values in engine config. Reject unknown phase keys in `phase_round_limits`. Validate `sessionId` format with regex pattern. Validate banner `variant` against allowed values.

- **Session Start IDOR** — Handle Supabase read error in `getExistingSessionOwner` (was silently returning "no row" on failure, potentially allowing session hijacking).

- **Sanitized Error Messages** — Short unrecognized errors no longer leak raw error text to users; always use the generic fallback. Fixed `.includes(".*")` literal string bugs in `sanitizeApiError` with proper regex patterns.

- **OpenRouter Model Gating** — `openrouter-models` route now respects `ALLOW_USER_API_KEYS` env var instead of hardcoding `allowUserKeys: true`.

## Infrastructure

- **DigitalOcean Migration** — All documentation, code comments, Dockerfile, and deployment configs updated from Render references to DigitalOcean App Platform.

- **Dual Log Storage** — Log files sync to both DigitalOcean Spaces (Singapore) and Supabase Storage S3, with per-provider S3 configuration.
