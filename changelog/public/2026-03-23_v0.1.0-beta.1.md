# v0.1.0-beta.1 — Inaugural Beta

**Release Date:** 2026-03-23

---

The first public beta of SN AI Agent — an AI-powered platform for building ServiceNow solutions through natural language conversation. Describe what you need; the AI builds it on your instance.

## Added

- **AI Chat Interface** — Have a conversation with an AI agent that builds ServiceNow solutions for you. Responses stream in real-time so you can follow along as the agent works.
- **Spec-Driven Development (SDD) Mode** — A structured development workflow that takes your request through Spec, Design, Scope Selection, Implementation, Testing, and Deployment — with your approval at each gate before moving forward.
- **Multiple ServiceNow Tools** — The agent can create and manage Business Rules, Script Includes, Client Scripts, UI Policies, ACLs, Update Sets, Notifications, Scheduled Jobs, and more — all from a single chat.
- **Multi-AI Provider Support** — Choose between Anthropic Claude or 100+ models through OpenRouter. Use whichever model fits your task best.
- **Flexible Access Tiers** — Try the app for free with daily limits, sign up for a higher quota, or bring your own API key for unlimited usage.
- **Email Sign-Up with OTP** — Secure account creation with email verification and one-time password codes. Includes password reset and magic link sign-in.
- **Dark and Light Theme** — Switch between dark and light modes. Your preference is remembered across sessions.
- **File and Image Attachments** — Attach PDFs, Word documents, Excel files, and images directly in the chat to provide richer context for your requirements.
- **Smart Suggestions** — The app suggests relevant prompts based on your connected ServiceNow instance, helping you discover what the agent can do.
- **Live Agent Activity** — See what the agent is doing in real-time — which tools it is calling, what phase it is in, and its progress through your request.
- **Focus Mode** — Automatically collapses sidebars during deep work sessions, giving you a distraction-free chat experience.
- **Chat Search and Table of Contents** — Search through your conversation and jump between development phases using a contextual table of contents.
- **Feedback and Bug Reporting** — Submit feedback or report bugs directly from the app, with optional screenshot capture.
- **Prompt Enhancement** — An AI-powered prompt improver that refines your request for clarity and adds ServiceNow-specific context before sending.
- **Reliable Update Set Capture** — A multi-layer system ensures every artifact the agent creates is captured in the correct update set, even when working across scopes.
- **Custom Scope Support** — Work in Global or custom application scopes. The agent handles scope switching automatically with multiple fallback strategies.
- **Multiple Auth Methods** — Connect to your ServiceNow instance using Basic auth, OAuth 2.0, or browser-session authentication.
- **Slash Commands** — Type `/` to access quick commands for common actions.
- **Message Queue** — Send follow-up messages while the AI is still processing. They are queued and delivered in order.
- **Mobile-Friendly Design** — Use the app on any device. The layout adapts to phones, tablets, and desktops across Safari, Chrome, and Edge.
- **Landing Page** — A public-facing page that introduces the product with feature highlights and a getting-started flow.

## Security

- **Rate Limiting** — Built-in protection against abuse on all endpoints.
- **Input Validation** — All inputs are validated to prevent injection and malformed data.
- **Content Sanitization** — User-generated content is sanitized to prevent XSS.
