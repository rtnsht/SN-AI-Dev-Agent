## Feature Details

### Voice Input (`f1832c1`, `85b0933`)

3-tier fallback chain:

```
Tier 1: Web Speech API (Chrome/Edge/Safari)
  └─ onerror ──▶ Tier 2: transformers.js Whisper (Web Worker, ~41MB cached in IndexedDB)
                   └─ catch ──▶ Tier 3: POST /api/transcribe (OpenAI Whisper, ~$0.006/min)
```

Pre-launch hardening:
- Safari/iOS: `audio/mp4` mimeType + try/catch on MediaRecorder constructor
- Worker crash resilience: onerror handler + 120s timeout on `transcribeLocal`
- Dynamic filename from MIME type (not hardcoded `.webm`)
- iOS AudioContext created in user gesture chain via `ensureAudioCtx` ref
- Float32Array transferred (not copied) to Worker
- Worker busy guard prevents concurrent transcription corruption
- CSP: `script-src` includes esm.sh, `worker-src 'self'`
- `/api/transcribe` added to `PUBLIC_PATHS`

Fix: `Permissions-Policy: microphone=()` → `microphone=(self)`. Differentiate fatal vs non-fatal errors in `onerror`. Show inline error banner for fatal (`not-allowed`, `network`, `audio-capture`).

## Bug Fix Details

### Cloudflare RSC Cache Poisoning (`bb25dc7`)

Root cause: Cloudflare ignores `Vary: RSC` and caches RSC flight data identically to HTML. Fresh visitors get raw `:HL[...]` text.

Fix in `next.config.ts`:
- Dynamic routes: `Cache-Control: private, no-store, no-cache, must-revalidate` + `CDN-Cache-Control: no-store` + `Cloudflare-CDN-Cache-Control: no-store` + `Vary: RSC, Next-Router-State-Tree, Next-Router-Prefetch`
- Static `/_next/static/*`: `Cache-Control: public, max-age=31536000, immutable`

### Mermaid Rendering (`6e6faf1`, `bccc84e`, `ad8a034`)

Three separate fixes:
1. Pre-validation: `mermaid.parse()` before `mermaid.render()` prevents DOM error banners
2. Init race: module-level Promise serializes concurrent mounts; reset on rejection so future diagrams retry
3. State reset: `MessageBubble` resets svg/error/view when `mermaidCode` prop changes
4. SSR safety: `Date.now()+counter` replaces `crypto.randomUUID()` for diagram container IDs

### Provider Error Taxonomy (`6e6faf1`, `ad8a034`, `7d430f9`)

Unified error codes: `provider_rate_limit`, `provider_auth`, `provider_billing` with `usedServerKey` flag.

- Non-streaming (`chat/route.ts`): all three codes handled with BYOK gate trigger
- Streaming (`chat-stream/route.ts`): SSE event handler detects provider errors inline (was missing)
- `chat-stream` outer catch: added `provider_auth` and `provider_billing` branches for parity

### Session Binding Leak (`bccc84e`)

`key-resolver.ts` `sessionBindings` Map had no size limit. Added:
- `SESSION_BINDINGS_MAX = 10_000`
- `SESSION_BINDINGS_EVICT_BATCH = 2_000`
- `evictOldestBindings()` called after every `set()`

### Assistant Prefill Error (`6e6faf1`)

Claude 4.5+ rejects requests where the last message is an assistant message (prefill). Planner data was being appended after the last user message. Fix: splice before the last user message.
