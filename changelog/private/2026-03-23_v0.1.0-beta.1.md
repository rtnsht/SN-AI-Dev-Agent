# v0.1.0-beta.1 — Inaugural Beta

**Release Date:** 2026-03-23
**Status:** Published

---

The first public beta of SN AI Agent — an AI-powered platform for building ServiceNow solutions through natural language conversation. Describe what you need; the AI builds it on your instance.

## Added

- **AI Chat Interface** — Conversational interface powered by Claude and OpenRouter with real-time streaming responses for building ServiceNow solutions through natural language.
- **Spec-Driven Development (SDD) Mode** — Structured 6-phase SDLC pipeline (Spec → Design → Scope Selection → Implementation → Testing → Deployment) with phase gates and user approvals at each checkpoint.
- **80+ ServiceNow MCP Tools** — Full tool coverage for Business Rules, Script Includes, Client Scripts, UI Policies, ACLs, Update Sets, Notifications, Scheduled Jobs, and more.
- **Multi-AI Provider Support** — Choose between Anthropic Claude (native) or OpenRouter (100+ models). Prompt caching reduces costs by approximately 90% on cache hits.
- **3-Tier Access System** — Anonymous (IP + instance rate-limited), Authenticated (daily quota), and BYOK (unlimited) tiers with Supabase-backed tracking.
- **Admin Panel** — 7-tab admin dashboard for managing access requests, users, invite codes, banners, trials, access tier configuration, and session logs.
- **Email + OTP Authentication** — Secure sign-up flow with email verification, OTP codes, password reset, and magic link support. Session management with automatic expiry.
- **Dark/Light Theme System** — Full theme support with CSS custom properties, persistent preference via localStorage, and smooth transitions.
- **File and Image Attachments** — Attach PDFs, Word documents, Excel files, and images directly in the chat for richer requirement input.
- **AI Suggestion Panel** — Instance-aware prompt suggestions powered by a context engine, with categorized prompts for common ServiceNow development tasks.
- **Inline Agent Activity Display** — Real-time visibility into what the AI agent is doing — tool calls, phase transitions, and progress indicators displayed inline in the chat.
- **Focus Mode** — Auto-collapses sidebars during deep work sessions, maximizing the chat area for uninterrupted interaction.
- **Chat Search and Table of Contents** — Search through conversation history and navigate between SDLC phases with a contextual TOC.
- **Feedback and Bug Reporting** — In-app feedback form with screenshot capture and file attachment support. Reports are saved to Supabase for admin review.
- **Banner and Announcement System** — Admin-managed site-wide banners with scheduling (start/end dates), page targeting, and semantic variants (info, warning, success, error).
- **Session Telemetry and Logging** — Real-time telemetry dashboards, session log persistence to Supabase, and round-by-round activity tracking with token usage.
- **Prompt Enhancement Engine** — AI-powered prompt rewriting that improves clarity, adds ServiceNow context, and suggests better phrasing before sending.
- **Update Set 3-Layer Capture Defense** — Session-based capture, post-creation move, and GlideUpdateManager2 fallback ensure artifacts are never lost during deployment.
- **Custom Scope Switching** — 5-tier fallback for scope switching: Concoursepicker API, ScopeHelper REST, user preference write, browser automation, and manual.
- **Multiple ServiceNow Auth Methods** — Basic authentication, OAuth 2.0 with PKCE flow, and browser-session authentication for connecting to ServiceNow instances.
- **Slash Commands and Command Palette** — Type `/` to access quick commands. Power users can use the command palette for rapid navigation and actions.
- **Message Queue** — Type follow-up messages while the AI is still processing. Messages are queued and sent sequentially after the current response completes.
- **Responsive Design** — Mobile-friendly layout with adaptive sidebar panels, touch-optimized controls, and cross-browser support (Safari, Chrome, Edge).
- **Configuration-Driven Branding** — Customize the app name, logo, colors, taglines, hero content, and all branding elements through environment variables.
- **Landing Page** — Public-facing landing page with hero section, feature highlights, trust indicators, step-by-step flow, and call-to-action.

## Security

- **Rate Limiting** — Per-IP and per-user rate limiting on authentication, chat, and session-start endpoints to prevent abuse.
- **Input Validation** — All API request bodies validated through strict Zod schemas to prevent injection and malformed data.
- **HTML Sanitization** — DOMPurify-based sanitization for all user-generated HTML content, including banners and feedback reports.
- **Admin Role-Based Access Control** — All admin API routes protected with session validation and admin role verification.
